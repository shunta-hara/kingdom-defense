# 王都防衛戦記〜予知夢の戦記〜 仕様書

## 概要

ブラウザで動作するファンタジー世界観のクリッカー×タワーディフェンスゲーム。プレイヤーは城をクリックして金貨を稼ぎ、6種類の兵士を雇用・育成しながら押し寄せる敵Waveを自動撃退する。転生（予知夢）システムにより周回プレイで永続強化が積み重なり、長期的な成長を楽しめるループ構造を持つ。プロトタイプ（React + インラインスタイル）をReact + Vite + TypeScript + Zustandのプロダクション構成に移行しながら、セーブ機能・ビジュアル強化・BGM・モバイル対応を追加実装する。

## UXフロー

1. **初回起動**: タイトル「王都防衛戦記〜予知夢の戦記〜」が表示され、城のクリックゾーンが目に入る。
2. **序盤（Wave 1-5）**: 城をクリックして金貨を貯め、槍兵・弓兵を雇用。Wave開始ボタンで最初の戦闘へ。
3. **育成ループ**: Waveクリアボーナス金貨で兵士を追加雇用し、レベルアップとスキル習得で戦力を強化する。
4. **中盤（Wave 5-15）**: 魔術師・聖騎士が仲間になる。スキルツリーを育て、Wave解放条件（Lv5）を目指す。
5. **上級兵種解放**: 槍兵Lv5+魔術師Lv5で魔剣士解放。弓兵Lv5+聖騎士Lv5で竜騎士解放。ログに演出が流れる。
6. **転生判断**: Wave数が進んでも突破できなくなったら転生を検討。転生モーダルで獲得欠片数を確認し判断する。
7. **転生後**: 「また同じ夢を見ている——」フレーバーテキストが流れ、新たな周回が始まる。欠片で予知強化を購入すると序盤から有利になる。
8. **繰り返し**: 転生を重ねるほど予知強化が積み重なり、より深いWaveに到達できるようになる。

## 非機能要件

- **信頼性**: セーブデータの破損を防ぐため、localStorageへの書き込みはtry-catchで保護する。バージョンフィールドを持ち、旧形式データを安全に扱う。
- **パフォーマンス**: 60FPSを目標とし、setIntervalベースの戦闘ループはrequestAnimationFrameに移行しない（UIと分離するため）。敵の最大表示数を12体に制限し、DOM更新コストを抑える。Reactの再レンダリングは Zustand のselectorで必要なコンポーネントのみに限定する。
- **モバイル対応**: iOS Safari / Android Chrome を主対象とし、375px〜1440px幅で動作保証する。タッチイベントとクリックイベントの両方に対応する。
- **アクセシビリティ**: ボタンには `aria-label` を付与する。色のみで情報を伝えるUIは作らない（HP バーに数値表示を併用）。
- **テスト**: Vitestでゲームロジック（ダメージ計算・Wave生成・転生計算・セーブ/ロード）の単体テストを実装する。UIコンポーネントのテストはSprint 10以降に検討する。
- **ビルド**: Vite + TypeScript でビルドし、`dist/` フォルダにHTMLをホスティングできる形式で出力する。チャンクサイズ警告が出ないよう、必要に応じてdynamic importを使用する。
