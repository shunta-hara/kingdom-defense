# アーキテクチャルール

## ディレクトリ構成

```
src/
├── types/          # 型定義のみ（ロジックなし）
├── constants/      # 定数・ゲームパラメータ
├── stores/         # Zustand ストア（ゲーム状態管理）
├── hooks/          # カスタムフック（ゲームループ・ロジック）
├── components/     # React コンポーネント（表示専用）
│   ├── game/       # ゲーム固有コンポーネント
│   └── ui/         # 汎用UIコンポーネント
├── utils/          # 純粋関数ユーティリティ
├── assets/         # 画像・音声
└── App.tsx
```

## 禁止事項

- コンポーネントにゲームロジックを書かない（hooks/ か stores/ に置く）
- `stores/` から `components/` を import しない（逆方向のみ許可）
- `types/` から他のモジュールを import しない（型定義のみのファイルにする）
- 1ファイル 300 行を超えない（超えたら分割を検討する）

## 状態管理

- ゲーム状態は Zustand で一元管理する
- コンポーネントのローカルstate は UI状態のみ（モーダル開閉・アニメーションフラグなど）
- セーブ/ロードは `stores/` の persist ミドルウェアで処理する
